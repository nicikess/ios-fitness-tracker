# iOS Run & Ride Tracker

Swift/UIKit app that tracks runs and bike rides using CoreLocation and stores the activity history on-device with CoreData. Built with colleague Andreas Trippel as the capstone project for an iOS development course at HSLU, guided by Ubique, during my Bachelor's.

## Getting started

1. Open `running-app/running-app.xcodeproj` in Xcode.
2. Build and run on a simulator or device, allowing location permissions when prompted.
